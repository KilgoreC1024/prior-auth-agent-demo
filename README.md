# Prior-Authorization Checklist Agent — live browser demo

MBA agentic-AI course project. The full agent runs client-side: policy retrieval and the
deterministic completeness check are JavaScript; the two reasoning steps are real LLM calls
made directly from your browser (IU Kelley LLM hub — requires IU VPN — or your own Anthropic key).

All payers, policies, and patients are synthetic. Not medical or coverage advice.
