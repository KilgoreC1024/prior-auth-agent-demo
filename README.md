# Prior-Authorization Checklist Agent

MBA agentic-AI course project (X500 Design Studio, Team 2). An AI agent that checks
whether an insurance prior-authorization submission contains every document the payer's
policy requires, prices the financial exposure of submitting incomplete, and escalates
ambiguous cases to human review.

**Live app (no install):** https://kilgorec1024.github.io/prior-auth-agent-demo/
Bring your own LLM token (IU Kelley hub on the university VPN, or an Anthropic API key).

All payers, policies, patients, and dollar figures are synthetic — coursework only,
not medical or coverage advice.

## How it works (short version)

1. **Retrieve** — deterministic keyword scoring finds the governing policy; near-ties or
   no-match escalate to a human before any LLM call.
2. **LLM reads** — extracts required documents and *decides* whether the policy
   cross-references an addendum; if so, a second retrieval merges its requirements.
3. **Deterministic tools** — `completeness_check()` (what's missing) and
   `financial_impact()` (what submitting anyway is expected to cost).
4. **LLM writes** — checklist, LOW/HIGH risk flag, plain-English explanation, using only
   tool-provided figures. Follow-up chat is grounded in the run record.

Design rule: the LLM never grades its own homework, and never invents its own numbers.
