# Beacon Insurance — Imaging & Functional Assessment Addendum BI-MN-7
## Supplemental Documentation Requirements for Aortic Valve Replacement (Policy BCN-AVR-205)

**Effective date:** March 1, 2026 (synthetic document for coursework — not a real payer policy)

### Purpose

This addendum supplements Policy BCN-AVR-205. The documents listed below are
**required in addition to** the documentation listed in Section 3 of the
base policy. An aortic valve replacement prior-authorization request is not
complete until all base-policy documents and all addendum documents have
been received.

### Additional Required Documentation

1. **Cardiac CT angiography report** — gated CT of the aortic root, annulus,
   and iliofemoral access vessels (required for all TAVR requests; required
   for SAVR when hybrid or minimally invasive approaches are planned)
2. **Frailty assessment documentation** — a validated frailty measure
   (e.g., gait speed, grip strength, or Katz index) completed within 90 days

### Application

Reviewers must verify the presence of both addendum documents before issuing
a completeness determination. Absence of either document requires the
request to be pended under the standard set in Section 5 of BCN-AVR-205.
